方案 1：GitHub Pages (推薦 • 永久免費)

適合個人作品集、報告展示與開源託管
  1. 在 GitHub 上新建一個名為 50-startup-ml 的公開倉庫 (Public Repo)。
  2. 在本地終端機執行以下指令推送專案代碼： 
    git init
git add .
git commit -m "feat: 50 Startups CRISP-DM Web App"
git branch -M main
git remote add origin https://github.com/您的帳號/50-startup-ml.git
git push -u origin main
  3. 進入 GitHub Repo 的 Settings > Pages。
  4. 在 Branch 選擇 main 並指定 / (root)，點選 Save。
  5. 1 分鐘後即可在全球網址 https://您的帳號.github.io/50-startup-ml/ 瀏覽！
